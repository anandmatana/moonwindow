# MoonWindow — Phases 2 to 4 Roadmap

All phases remain web-based. Native Android/iOS apps are explicitly out of scope.

## Phase 2 — Personal sky companion

Goal: improve repeat usage after Phase 1 proves reliable.

- Saved locations and preference sync
- Browser push alerts for moonrise, full Moon and chosen occasions
- Configurable visibility thresholds
- Seven-day Moon and weather planner
- More festival/occasion landing pages
- Shareable Moon status cards
- Observation notes and optional photo metadata
- Accessibility audit and multilingual foundation
- Privacy-safe product analytics dashboard

Exit criteria: users can plan, save and return without re-entering preferences.

## Phase 3 — Community and discovery

Goal: add trustworthy local context without weakening astronomical accuracy.

- Local Moon sighting reports with moderation
- Obstruction and horizon notes by approximate area
- Public observation map using coarse location only
- Community photo gallery with consent and attribution
- Regional calendars and translated content
- Embeddable Moon widget for publishers
- Public read API with rate limits
- Progressive Web App background refresh improvements

Exit criteria: community information improves local usefulness while precise user location remains private.

## Phase 4 — Advanced web sky platform

Goal: deliver richer browser-based sky guidance and sustainable operations.

- WebXR-enhanced sky mode where supported
- Camera overlay for Moon path and rise trajectory
- Horizon calibration and obstruction-aware guidance
- Additional bright-object discovery (planets and major events)
- Accounts, teams and educator views
- Premium alert and planning features
- Operational dashboards, abuse controls and provider failover
- Commercial weather provider migration if required

Exit criteria: MoonWindow is a reliable, scalable web sky platform with a clear sustainable model.

## Product constraints through Phase 4

- Web/PWA first; no native app codebase
- Astronomy calculations remain client-side where practical
- Camera frames and sensor streams never leave the device
- Religious observations remain informational, not official declarations
- Every prediction exposes uncertainty and real-world obstruction limits
